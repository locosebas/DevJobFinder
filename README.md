# Plan de estudio Senior — DevOps / Plataforma + IA y Senior SWE

Plan de estudio para trabajar **con Claude Code como tutor**: temas,
roadmaps, exámenes de autoevaluación, pruebas técnicas resueltas,
presentaciones de entrevista y herramientas para la búsqueda de empleo.

## Cómo empezar

1. Haz un fork o copia de este repo y ábrelo con Claude Code.
2. Escribe cualquier cosa (ej. "hola"): como `perfil/perfil.md` está en
   **PENDIENTE**, Claude te guiará por el onboarding (`perfil/onboarding.md`):
   tu perfil, tu objetivo, tu experiencia, un examen diagnóstico y la
   personalización del repo.
3. Después pide cosas como *"explícame Private Endpoints"* o *"dame un examen
   de Kubernetes nivel intermedio"* (más ejemplos en
   `devops-senior/examenes/README.md`).

## Estructura

| Carpeta | Qué hay |
|---|---|
| `perfil/` | Tu perfil y la guía de onboarding |
| `devops-senior/` | Ruta DevOps / Plataforma + IA: roadmap, 28 temas, exámenes, fórmulas "de cero", recursos, certificaciones |
| `swe-senior/` | Ruta Senior Software Engineer (sistemas distribuidos, Kafka, Clojure, etc.) |
| `pruebas-tecnicas/` | Soluciones y presentaciones de pruebas técnicas reales (material de estudio) |
| `presentaciones/` | Índice de presentaciones |
| `busqueda-empleo/` | Scripts para postular por lotes, registro de postulaciones y **estadística colectiva anónima** (`estadisticas/`): tasas de respuesta reales por portal y tipo de rol, a la que puedes sumar tus números |
| `herramientas/` | `personalizar.py`: pone tus datos en los marcadores del repo |

## Sobre los marcadores

Este repo se publicó sin los datos de su autor original. Verás marcadores
como `[TU_NOMBRE]` (se reemplaza con `herramientas/personalizar.py`) y
`[EMPRESA_1]` (historia laboral de ejemplo: reescríbela con la tuya). Todos
los niveles de dominio empiezan en ⬜.
